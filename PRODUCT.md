# CraftCV

## Register

product

## Users and purpose

Developers tailoring a CV to a specific job using evidence from their local Git repositories. Success is a reviewed, truthful set of relevant bullets with inspectable sources.

## Design direction

User-approved: focused light desktop workspace, compact controls, evidence-first review panel. A developer reviews an application at a desk in daylight and needs readable text and calm, deliberate choices.

## Principles

Local work stays local unless explicitly shared. Evidence precedes claims. Never imply authorship or quantified impact from source code alone. Every action has visible progress and an honest outcome. Keyboard access, readable contrast and reduced-motion support are defaults.
